- 실행: https://bmrgoodway.github.io/tower-defense/

## 2인 모드 준비 턴 (웨이브 전 교대)

2인 모드(1v1 맞대결·2인 협동)는 웨이브가 시작되기 전에 **1P 준비 턴 → 2P 준비 턴 → 웨이브 시작** 순서로 각자 한 번씩 자기 진영을 정비합니다. 한 화면을 마주 보고 있어도 두 사람의 터치가 겹치지 않습니다.

| 단계 | 조작 가능 | 잠금 |
| --- | --- | --- |
| 1P 준비 턴 | 1P 보드·HUD (타워 설치·강화·판매, 보내기) | 2P 진영에 `1P 준비 중…` 오버레이, 터치·버튼 차단 |
| 2P 준비 턴 | 2P 보드·HUD | 1P 진영에 `2P 준비 중…` 오버레이, 터치·버튼 차단 |
| 웨이브 | 양쪽 자유 | — |

- 1P는 HUD의 `준비 완료`로 2P에게 넘기고, 2P는 `웨이브 시작`으로 해당 웨이브를 출발시킵니다.
- 준비 턴 동안에는 게임 시간이 멈춰 적 이동·사격이 정지합니다. 남아 있던 적은 웨이브가 시작되면 그대로 이어서 움직입니다.
- 2P 쪽 HUD·안내 문구는 기존 규칙대로 180° 회전되어 P2 방향에서 읽힙니다.
- 1인 솔로는 교대 없이 기존과 동일하게 바로 플레이합니다.
